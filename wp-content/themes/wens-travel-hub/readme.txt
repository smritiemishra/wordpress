== Description ==

WENS Travel Hub is a modern, fully responsive child theme of WENS Haelo, specifically designed for travel agencies, tour operators, destination marketers, and travel enthusiasts. Built with the WordPress Block Editor and WP Travel Gutenberg Blocks, this theme offers a flexible and intuitive website-building experience, allowing users to customize every aspect of their site without any coding knowledge. With clean layouts, engaging destination showcases, and professionally crafted templates, creating an attractive travel website is simple and straightforward. The theme integrates seamlessly with WP Travel, making it easy to display tour packages, featured destinations, travel itineraries, booking details, and blog content in a well-organized and visually appealing manner. Whether you are promoting adventure tours, holiday packages, cultural experiences, or travel guides, WENS Travel Hub provides customizable block patterns, pre-designed templates, and responsive layouts to help you effortlessly create a professional travel website that offers an engaging experience for your visitors.

== Installation ==

1. In your admin panel, go to Appearance -> Themes and click the 'Add New' button.
2. Type in WENS Travel Hub in the search form and press the 'Enter' key on your keyboard.
3. Click on the 'Activate' button to use your new theme right away.
4. Navigate to Appearance -> Editor in your admin panel and customize to taste.
